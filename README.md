# ZoolChat

Android-first messaging and calling app. This repository contains the current **v0.24 Free Two-Phone Beta Release Candidate** source bundle and a GitHub Actions workflow that builds the Android LAN beta APK.

## Current build target

- Android APK: `lanBetaDebug`
- Source bundle: `release/ZoolChat_v0_24_Presence_Typing_Build_RC_Source.zip`
- GitHub Actions artifact: `ZoolChat-v0.24-lanBetaDebug-apk`

The beta is designed for two Android phones using the included free local/private-network server stack.
